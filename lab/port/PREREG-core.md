# #459 — the computing core alone against the shipped engine (written before any core run)

The question (the user and Gemini, after #458's census answers): does the computing core alone find as much as the whole engine?
Everything with a measured effect on the number lives in the computing layer; #430's screen resolves only about 1.5x and saw one
layer (the mind, which is mutation). A whole-field comparison is the test that can see it.

**Arms.** The shipped field against the same engine with every older layer switched OFF in every universe, through each universe's
own knobs (`index.html#core`, which hands every universe `knob=` with the list below; nothing else changes):
- **Off (43):** the 41 layers of #430's list other than MIND, REPL_PREY and TASK_TROPHP (`NICHE_FRONTIER` ... `MOTIF_SELECT`, `FOUND`),
  plus `COSMOS` and `COSMOS_LAW`.
- **Kept:** TASKS and everything shipped in it (one currency, crowd price, five inputs, opening, ground, kept discoveries), the drain
  (`TASK_TROPHP`, #454), the drawn mind (`MIND`, #431), predation (`REPL_PREY`, #366).

**Before the set:** one short field (5 minutes) checks that a `#core` field boots, computes, and that every universe reports the 43 off
(seen().arm). It decides nothing about the question.

**The set:** 8 pairs, 25 minutes, each alone on the machine, one per launch, none stopped early; a pair cut by a restart is void and rerun.
Primary: F at the last sample, ratio core / shipped, per pair. Guard: size-17+ new functions.
- **CORE IS ENOUGH** if the median ratio is at least 1.00 and the size-17+ median at least 0.90. Then the older layers are removed from
  the engine in steps, each checked byte-identical against the `#core` world it reproduces, and the shipped world becomes the core.
- **THE OLD LAYERS WORK** if the median ratio is under 0.90, or 2 or fewer of 8 pairs are ahead. Then the follow-up is finding which:
  the 43 split into halves, tested the same way.
- **Otherwise INCONCLUSIVE:** nothing is removed, and the result says so.
Said before: #424 found random subsets of eleven switchboard mechanisms found less than all of them, and #427 found two layers off at
0.94, so the likelier outcome is THE OLD LAYERS WORK or INCONCLUSIVE.
