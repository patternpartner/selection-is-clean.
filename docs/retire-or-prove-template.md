# Retire-or-prove standing template

Standing rule for mechanism KEEP / DELETE pre-registrations. Adopt before numbers exist.
This is **not** a verdict on #241 (or any closed entry). Copy the clauses into the entry;
do not invent a result here.

## 1. Floor — min counted focals / seeds

- **KEEP requires ≥ 2 counted focals** (or ≥ 2 counted seeds when the claim is single-universe).
- If fewer than 2 count after the pre-registered budget (and any pre-registered one-shot extension), that is a **horizon miss**, not evidence. Do not KEEP on a horizon miss; do not DELETE the treatment as “failed” on a horizon miss either — say the budget and stop.
- Propose the same floor in every new entry unless the note explicitly raises it.

## 2. Direction — “helps” / “no worse”, not absolute-gap alone

- Absolute-gap MOVE / “matters” is **not enough** for KEEP.
- A counted focal **helps** only if the treatment arm is **no worse** on the named instruments than the control arm (define “no worse” per instrument in the entry: e.g. entropyRatio and kinds_late not lower; paid / alive not lower by the relative lines).
- **KEEP** only if the help / no-worse clause holds on at least the floor of counted focals.
- A treatment that MOVEs both counted focals the **wrong** way is DELETE (or dormant), not KEEP.

## 3. Counted-seed discipline

- A seed / focal **counts** only when the pre-registered **path under test actually ran** (name the liveness signal: e.g. `cell.inscribeNet > 0`, packets applied, chemExec, etc.).
- Sparks, fires, or posts that never reach the scored path do **not** count.
- Non-counted seeds may appear in a table for visibility; they are **not scored** and must not be re-read into the rule after seeing numbers.
- The peer (if present) is not scored unless the entry says so before the runs.

## 4. Pre-register the rule before numbers

- Write the arms, budget, floor, direction, instruments, counted definition, and DELETE touchlist **before** any decision-budget run.
- Results follow the rule as written. Do not revise thresholds after seeing the table.
- **DELETE removes the treatment only** (the lines / knob / write named in the touchlist). It does not reopen unrelated KEEP'd bundles.

## 5. Merger rule (reminder)

- Smoke green on the branch.
- Second-agent review before merge.
- **Do not merge yourself** from a support or measurement session unless the user explicitly names the merge.
